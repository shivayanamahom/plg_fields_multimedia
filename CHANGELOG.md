# Changelog

## 2.0.0 — 2026-10-27

Полная переработка плагина (прежние версии 1.x — внутренний прототип).

### Добавлено
- Два режима поля — «Галерея» и «Файлы»; режим выбирается один раз и после сохранения не меняется, настройки показываются только для своего режима.
- Нативный интерфейс: повторяемый subform Joomla со штатным полем «Медиа», подписью и alt; порядок — перетаскиванием.
- AJAX-загрузка с компьютера (кнопка и перетаскивание файлов), настройки берутся на сервере по id поля.
- Миниатюры с кэшем, сетка и слайдер на CSS scroll-snap, список и карточки для файлов.
- Просмотр крупно через WT Fancybox (WebAsset `wtfancybox`, если плагин включён) или встроенное окно на `<dialog>`.
- Переопределяемые макеты `layouts/plg_fields_multimedia/*` и `tmpl/multimedia.php`.
- Серверный фильтр значения, блокировка режима на сервере, удаление файлов вместе с записью (опция, только из папки поля, с проверкой ссылок).
- Тесты безопасности `tests/run.php`, сборка `tools/build.sh`, релиз через GitHub Actions, сервер обновлений.

### Изменено
- Ассеты перенесены в `media/plg_fields_multimedia/` и описаны в `joomla.asset.json`.
- Загрузка проверяет содержимое файлов (finfo, getimagesize), пересохраняет изображения через GD, создаёт защиту папки от выполнения скриптов.
- Нет inline-скриптов и стилей; подключение библиотек из CDN удалено.

### Удалено
- Режим «смешанных» полей (изображения и документы вместе) — создавайте два поля.
- Параметры, которые принимались от браузера (папка, лимиты, расширения).
