# Changelog

## 2.0.2 — 2026-10-28

### Исправлено
- Слайдер не прокручивался на сайтах, где шаблон задаёт `ul { overflow: hidden }` для текста материала (например, `.com-content-article ul`): правило обрезало список слайдов, и вместо прокрутки показывались только первые кадры при отключённых кнопках. Теперь список слайдера явно `overflow: visible`.
- Поле падало с ошибкой `getWebAssetManager() on null` (в консоли — `undefined method getDocument`), когда запрос идёт без страницы сайта: API, MCP-серверы, консольные команды. Без документа разметка выводится, а скрипты и стили не подключаются.

## 2.0.1 — 2026-10-27

### Исправлено
- Скрипты и стили плагина не подключались: в `joomla.asset.json` пути содержали папки `js/` и `css/`, которые Joomla добавляет сама. Затронуты админка и вывод на сайте.
- Загрузка с компьютера: кнопка теперь стандартная метка вокруг скрытого поля выбора файла (работает в любом браузере), обработчики перетаскивания висят на документе, загрузка больше не зависает молча при ожидании элементов ядра.
- Значения из формы (Registry-объекты) корректно разбираются серверным фильтром.

### Изменено
- Админская форма: строки в виде карточек в колонках, крупное превью, ряд кнопок «+», «−», перемещение на всю ширину; панель загрузки с подсветкой при перетаскивании файлов.
- В галерее одно поле «Описание (alt)» вместо двух (alt и подпись); оно используется как alt, подпись под фото и подпись в окне просмотра.
- Выбор режима поля — выпадающий список.

## 2.0.0 — 2026-10-27

Полная переработка плагина (прежние версии 1.x — внутренний прототип).

### Добавлено
- Два режима поля — «Галерея» и «Файлы»; режим выбирается один раз и после сохранения не меняется, настройки показываются только для своего режима.
- Нативный интерфейс: повторяемый subform Joomla со штатным полем «Медиа», подписью и alt; порядок — перетаскиванием.
- AJAX-загрузка с компьютера (кнопка и перетаскивание файлов), настройки берутся на сервере по id поля.
- Миниатюры с кэшем, сетка и слайдер на CSS scroll-snap, список и карточки для файлов.
- Просмотр крупно через WT Fancybox (WebAsset `wtfancybox`, если плагин включён) или встроенное окно на `<dialog>`.
- Переопределяемые макеты `layouts/plg_fields_multimedia/*` и `tmpl/multimedia.php`.
- Серверный фильтр значения, блокировка режима на сервере, удаление файлов вместе с записью (опция, только из папки поля, с проверкой ссылок).
- Тесты безопасности `tests/run.php`, сборка `tools/build.sh`, релиз через GitHub Actions, сервер обновлений.

### Изменено
- Ассеты перенесены в `media/plg_fields_multimedia/` и описаны в `joomla.asset.json`.
- Загрузка проверяет содержимое файлов (finfo, getimagesize), пересохраняет изображения через GD, создаёт защиту папки от выполнения скриптов.
- Нет inline-скриптов и стилей; подключение библиотек из CDN удалено.

### Удалено
- Режим «смешанных» полей (изображения и документы вместе) — создавайте два поля.
- Параметры, которые принимались от браузера (папка, лимиты, расширения).
